API каталога игр

GET /api/games — список. POST /api/games — добавить игру.

GET, PUT, DELETE /api/games/1 — прочитать, изменить, удалить игру.

Поля: title — название, genre — жанр, price — цена от 0.

Ответы: 200 — успех, 201 — создано, 204 — удалено, 400 — неверные данные, 404 — не найдено.
